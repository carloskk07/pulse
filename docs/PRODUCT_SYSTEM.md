# Product System

## North star

**Net contribution margin per verified daily active user.**

The faucet-like reward is a retention cost, not the business model.

## Initial funnel

Landing → account → welcome reward → best first quest → progress to withdrawal → first withdrawal → streak → active referral → return.

## Product principles

- One visible primary action per screen.
- Show reward + estimated effort before action.
- No fake scarcity, fabricated earnings or deceptive social proof.
- Reward quality derives from measured data.
- First value should happen before long onboarding.
- Mobile-first interaction and thumb-friendly controls.
- Visual identity: premium fintech clarity + restrained progression/game feel.

## V1 monetization

One monetization provider adapter and one payout adapter. Add providers only after inventory, margin or reliability data proves a bottleneck.

## V1 anti-abuse

Turnstile server validation, rate limits, account/IP/wallet signals, risk score, payout gating. Avoid aggressive fingerprinting until evidence requires it.

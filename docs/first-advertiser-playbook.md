# First Advertiser Playbook

## V13.2 demand wedge

Use two commercial doors instead of forcing every advertiser into the same funnel:

**Pulse Ads** is the low-friction traffic test. Current launch economics are a $5 minimum budget and $0.05 per qualified sponsored click. The viewer is not paid to click, impressions are not billed, and delivery is never promised before real inventory exists.

**Pulse Direct** is the higher-value verified-action product. Use it when the advertiser can define and verify a meaningful post-click event such as onboarding, an early product milestone, trial activation or another objective outcome.

Routing rule:

```text
needs traffic / wants to inspect quality first
→ Pulse Ads

needs a verified outcome / can provide callback evidence
→ Pulse Direct

not sure
→ qualify before creating any campaign
```

Do not require an account merely to express interest. The no-login advertiser intake creates a private CRM lead only. It does not create a campaign, budget, traffic entitlement or revenue.

For outbound prospects already marked `ready`, execute outreach before researching more companies. Use the prefilled draft only as a starting point and mark the CRM stage only after the contact actually occurs.

## Objective

Prove one real Pulse Direct loop with the smallest credible commercial experiment:

```text
real advertiser
→ prefunded campaign
→ one verified action
→ real user reward
→ Pulse contribution
→ advertiser result
```

Do not optimize for lead volume. Optimize for learning from a small number of high-fit companies.

## ICP v1

Priority 1: small/mid-size mobile game studios with:

- a live or near-launch free-to-play game;
- a measurable post-install event such as tutorial completion, level reached, first match or retained session;
- a public partnership/business contact;
- a launch, soft-launch or active growth window;
- enough product maturity to verify events server-side or through a reliable attribution route.

Why this ICP: mobile free-to-play growth is already operated through performance user acquisition, and rewarded acquisition is increasingly event/milestone oriented rather than install-only. Pulse Direct can therefore sell a familiar economic concept with a simpler, prefunded pilot.

## Pilot design

Default pilot hypothesis, not a fixed commercial promise:

```text
Budget                  $100–$500
Geography               1 country or narrow market
Verified action         1 event only
Completions             25–100
Duration                7–14 days
Funding                 prefunded before activation
User reward             defined before launch
Pulse contribution      positive before launch
Campaign cap            hard database limit
```

Avoid install-only pilots when a more meaningful early engagement event is available. The advertiser should be able to answer one question at the end: “Did we acquire users who completed the action we care about at an acceptable cost?”

## Qualification gate

Move a prospect from `researching` to `ready` only after confirming:

1. the company/product is real and currently active or close to launch;
2. the desired action is objective and technically verifiable;
3. the action is legally/policy compatible with Pulse;
4. a public business contact path exists;
5. a $100–$500 experiment is plausible for the company size/stage;
6. Pulse can describe a concrete pilot in one sentence.

`fit_score` is prioritization evidence, not proof of willingness to buy.

## First outreach

Subject options:

- `Small verified-user pilot for <Game>`
- `Pay for a milestone, not just an install`
- `<Game>: 25–50 verified player actions` 

Core message:

```text
Hi <Studio>,

I’m building Pulse, a prefunded reward marketplace for verified user actions.

Instead of paying only for an install, a small pilot can reward users after a milestone you choose — for example tutorial completion, first match, or reaching an early level. Budget and completion count are capped before launch, and Pulse only settles after the agreed event is verified.

I think <specific title> could be a good fit for a 25–50 user test in one market.

Would a small pilot be worth discussing?

Pulse for Business
https://pulse-phi-one.vercel.app/business
```

Do not claim audience size, conversion rate, ROAS, payout volume or advertiser demand that Pulse has not actually proven.

## Follow-up sequence

Day 0: personalized first contact.

Day 3–4, only if unanswered:

```text
Following up with one concrete version of the idea: <X> verified players in <country>, reward released only after <milestone>, with a hard prefunded cap. No long contract or open-ended spend.

If that is not useful for <Game>, no problem — I would rather know quickly than keep following up.
```

Day 7–10: final close-the-loop message. No repeated automated sequences after that unless the company replies or publishes a new relevant launch/growth event.

## Decision rule

The first advertiser is not selected by highest theoretical margin. Prefer the company that gives Pulse the cleanest proof:

```text
simple event
+ reliable verification
+ small prefunded budget
+ reachable operator
+ fast feedback
```

One clean $100 pilot is strategically more valuable than ten speculative integrations.
